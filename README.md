# Project Transcendence 飞升计划

## 模组列表：

- 魔改ProjectE（性能优化、炼金术、大后期才能合成交换桌等）
- Twlight Forest（提高拆解台成本，加强怪物使得前期不再能打过）
- Create及其附属模组（禁用蓝图大炮）
- Tinkers' Construct（魔改，带Create的思考、与Create交互、红石自动化）
- Farmers' Delight及其衍生模组
- 大量辅助模组（JEI、JER、FTB Ultimine、Tom's Simple Storage、Carpet、投影等）
- KubeJS

### 可能添加的模组：

- Mekanism、AE2等机械包；
- The Last Smith等战斗模组

## 大致的游戏玩法流程：

前期：以Create和Tinkers' Construct为主的科技主题生存，在这方面不锁科技；增加饥饿惩罚，让玩家提前制造Farmer's Delight的相关物品以避免饥饿；降低洗砂砾掉铁粒的概率，期望玩家制造原版刷铁机而不是Create的刷铁机

中期：使用Create制造成规模的暗物质产线、红物质产线（不能使用emc交换，故要求玩家制造好挖矿机），再通过怀表、凝聚器等原版ProjectE装置产生大量红物质，合成红物质拳剑等武器

后期：探索暮色森林，获取炼金必备的物品

大后期：制造炼金场所，炼金获得转化桌

## 其他说明

整合包包含任务系统的引导，以及对所有的内容都添加了“长按W思考”的功能，以便玩家熟悉游戏操作
